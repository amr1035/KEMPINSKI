# توزيع المدعوين - Kempinski
تشغيل محلي:  `node server.js`  ثم افتح http://localhost:3000
- index.html : المخطط + إضافة الأسماء للطاولات
- search.html : البحث عن اسم  -> view.html : المخطط مع تظليل الطاولة
- data.json : ملف الحفظ (نسخة احتياطية من /data.json)
متغيرات: PORT, DATA_DIR (مجلد حفظ data.json - اجعله على قرص دائم عند الاستضافة)
